# V11 abstract-surface generalization study

The [v10 fresh test](../eval/runs/ro-mmbert-v10-test-0020-comparison.json) fell from 45/48 exact development pairs to 28/72 test pairs, with 40/72 false reviews. Its training cards used a narrow Romanian field and Boolean vocabulary; batch 0020 used another. This study tests a targeted response: broaden **training** wording while leaving a separately rendered, sealed test. Consumed test rows from batches 0018–0020 never enter the fit. Their *field-name and Boolean vocabulary families* informed the new training lexicon, which is an explicit error-driven revision, not independent pretraining. The new test uses its own labels and `se confirmă`/`nu se confirmă` markers.

Batch [0021](../data/synthetic/batch-0021.preview.md) contains 2,304 abstract Romanian train cards: 48 typed one-fact state pairs per category, each rendered four ways. Batch [0022](../data/synthetic/batch-0022.preview.md) contains 144 development cards, 12 pairs per category. Batch [0023](../data/synthetic/batch-0023.preview.md) contains 144 test cards from a separate renderer and 12 pairs per category. The typed policy reference checks every negative and positive label before attestation. No card contains a realistic child utterance, disclosure, grooming exchange, response, or case paraphrase. Exact duplicates are checked over all cards. The expensive nearest-character-similarity audit samples every eighth **training** row; its note and count are recorded, and that sample is not evidence of complete surface independence. Development and test similarity checks use every row. Shared typed rule structures make this a synthetic generalization study, not authentic child-language validation.

## Fixed fit and development choice

Initialize a new rank-16/alpha-32 LoRA adapter on hash-pinned JHU mmBERT-base, with dropout 0.05 on `Wqkv`/`Wo` and a trainable two-class head. Use only batch 0021 for fitting. Each one-fact pair contributes primary category negative/positive tasks. An A1 or S1 pair additionally contributes two **negative** tasks for the other applicable response category, as in v10. Use the unchanged Romanian v4 rule prompt. Fit three epochs with seed 20260930, batches of two pairs, maximum 256 tokens, AdamW learning rate 1e-4, linear 10% warmup and decay, and the v10 loss: primary cross-entropy + 0.5 pair `softplus` ranking + 0.5 cross-category negative cross-entropy where applicable. No test batch can enter fitting or development.

At each epoch, score batch 0022 once. Candidate shared thresholds are 0, 0.5, 1, and midpoints between distinct pooled development scores. Choose by complete exact development pairs, then exact cards, then fewer false reviews on negative cards, then threshold nearest 0.5, then earlier epoch, then lower threshold. Commit the record, row-level development scores, and selected adapter hash before batch-0023 inference. The development split is itself a synthetic surface, so a strong development score is only a selection signal.

## Frozen test and decision

Evaluate the selected v11 adapter once on batch 0023. Evaluate unchanged, previously selected v10 and v9a adapters on those same cards with their own frozen thresholds. Preserve row scores, strict validity, exact cards and pairs, directional flips, negative-card false reviews, per-category TP/FP/FN and precision/recall, model/test/prediction hashes, and paired discordance. Include always-review and never-review references. V11 meets its **symbolic-card** target only at ≥58/72 exact pairs, ≥9/12 positive recall in each category, ≤7/72 false reviews, and more exact pairs than both comparators. Batch 0023 is consumed after the first inference. Even success would not establish disclosure detection on authentic child language, Ukrainian model performance, or comprehension by children. Exact declared-contract checks remain the operational path.
