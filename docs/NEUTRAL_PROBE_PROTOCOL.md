# Frozen benign Romanian request specificity probe

The selected v11 mmBERT adapter has been tested on **abstract symbolic cards**, not ordinary message wording. This out-of-domain probe asks whether it wrongly flags original, harmless Romanian requests as D1. The [48 texts](../data/probes/ro-neutral-0001.json) were authored for this study, are grouped into six everyday topics, contain no real messages or realistic disclosure/grooming content, and have the fixed empty-label reference. They are not training or development data. Their existence does not prove that any real child's language is represented.

Before inference, commit the exact data, this protocol, and [runner](../eval/run_mmbert_neutral.py). The runner must reject an uncommitted change to any of those inputs or to the selected adapter manifest and weights. Freeze mmBERT base revision `c5955035435e2bf121cde7f3c8863ef52ff35d82`, v11 adapter SHA-256 `0b2144bd7a369e0b5f422a9a309bb70cfec65682de4a530aa2a8bc6283cd50bb`, v4 prompt, and shared threshold `0.9835666418075562`. Prefix every request with the same fictional metadata, `Sursa declarată: minor. Mesaj: `, so the source role is present. Run each text once as a `message` through the committed adapter; record its D1 score, label, group, source hashes, and group totals. Do not alter the threshold after looking at these texts.

The prospective specificity target is **at most 2/48 false D1 reviews** overall and **at most one in any group of eight**. A pass only shows that this adapter mostly abstained on these 48 authored benign requests. A failure identifies a concrete out-of-domain false-positive problem. Neither outcome estimates D1 recall, balanced accuracy, calibrated risk, authentic child-language specificity, or Ukrainian behavior. Keep the raw result either way, then use a different, newly registered test for any changed model or decision rule.
