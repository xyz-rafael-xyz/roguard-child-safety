# V17 prospective D1 cutoff transfer

V16 failed its registered abstract-prose target because 15 of 24 D1 negative cards received a review label. Its saved test scores are consumed and are used only to motivate this question; no score, row, or threshold from batch 0030 may select V17. The hypothesis is that a separately selected, more conservative D1 cutoff can retain D1 recall while reducing false review across two **new** Romanian abstract surfaces. This is calibration of the frozen V16 research model, not additional training or a claim about real child language.

The registered generator produces batch 0031 (development) and batch 0032 (sealed test), each with 96 cards in 48 adjacent one-fact pairs: 24 D1 pairs and 24 S1 pairs. The two batches have separate clause vocabularies and shuffled orders. Every card describes invented role, signal, or response-field states; none contains a child message, realistic disclosure, or proposed response. Attestation checks exact reproduction, labels against typed reference rules, duplicates, and character-surface separation. Shared underlying rule structures make this a narrow transfer test.

Freeze the selected V16 adapter weight SHA-256 `9f3ccab9b75b9aad5b42739518348bc3af84fd8037d17f3b49ecdb741a858f1d` and its committed Romanian v4 prompt and base revision. Score batch 0031 once. Keep the S1 cutoff exactly 0.5. Candidate D1 cutoffs are 0, 0.5, 1, and every midpoint between sorted unique D1 development scores. Prefer candidates with **at least 21/24 D1 positives recalled**; among them select the most exact D1 pairs, then fewer D1 false reviews, then higher D1 recall, then the higher cutoff. If none meets the recall floor, select by D1 recall, then exact D1 pairs, fewer D1 false reviews, and higher cutoff; record that development gate failure. Commit all development scores, the chosen cutoff, and hashes before test inference. The S1 cutoff and both model weights stay fixed.

On the untouched batch 0032, compare V17 with V16 at its original 0.5 shared cutoff, using the **same** saved model scores for both policies. The registered success criterion is at least **42/48 complete pairs**, at least **21/24 positive recalls in each of D1 and S1**, at most **4/48 false reviews** on negatives, and more complete pairs than original V16 on the same test. Save row-level scores and both decisions. A failed criterion remains a reported failure, even if one metric improves. This synthetic test cannot estimate recognition of authentic Romanian disclosures, Ukrainian accuracy, or real response quality.
