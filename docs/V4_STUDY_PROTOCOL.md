# V4 conversation study: prospective protocol

The task is recognition of a personal support-seeking signal in a fictional conversation attributed to a minor. A fictional quotation or grammar exercise is a negative; a personal statement followed by a retraction remains positive. These are restricted task labels, not judgments that quoted or third-party content is harmless.

The generator uses 24 training, eight development and eight test settings per language, crossed with 12/6/6 independently worded need phrases respectively. Each cross has personal, fiction, retraction, quotation and direct forms; ordinary negatives are deduplicated by setting. Training alone receives lowercase/punctuation and diacritic/mixed-glyph variants. Scenario-family, setting, need and discourse IDs are retained. Splits have distinct settings, need phrases and discourse frames. Combinations and style variants are correlated, and all originate with one project author. No row is a real case. Label rules are imperfect synthetic assumptions and do not establish task validity on real language.

Before fitting, commit this protocol, generator, encoder and trainer. Candidate experiment 1 compares a 2–5 character TF–IDF logistic model (C 0.5, 2, 8; at most 45,000 features) and logistic heads (C 0.1, 1, 10) on mean-pooled, L2-normalized pinned mmBERT-base features multiplied by ten. Embeddings are frozen, not a claim of full encoder fine-tuning. Experiment 2 evaluates fixed semantic ensemble weights 0.25, 0.5, 0.75 and 1.0 using selected component models. Thresholds are selected per language from 0.10 through 0.90 in 0.02 increments. Rank thresholds by balanced accuracy, recall, closeness to 0.5; models by worst-language balanced accuracy, total balanced accuracy, then total recall, retaining earlier candidates on ties. Uncertainty is a prespecified band of 0.08 either side of the cutoff, not calibrated safety probability.

Commit selection and compressed fitted heads before generating/scoring the test. Report current v3 last-message baseline, new fast model, semantic model and ensemble with per-language confusion counts, positive recall, false alerts per 1,000 negatives, precision, balanced accuracy, exact family consistency and per-discourse errors. Report coverage, misses and false alerts among decided examples plus overall unresolved review workload; do not hide abstentions. Include descriptive Wilson intervals and dependency limitations. A candidate qualifies as a measured improvement only if both languages improve balanced accuracy over the v3 comparator without lowering recall. No superiority claim over external guardrails is implied.

Separately evaluate unsupported-script handling, role boundaries, prompt-like strings, typos and English mixing as diagnostic stress tests. Measure warm CPU latency, startup cost and memory context separately; compare dynamic int8 semantic features to float on the same fixed examples and report output changes. Quantization cannot be promoted solely for speed. If a test is used for repair, mark it consumed and author a new holdout before another release accuracy claim.
