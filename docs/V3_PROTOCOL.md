# Frozen Romanian paired-card pilot, v3

This protocol is committed before model fitting or opening the test predictions. The [generator](../training/generate_counterfactual.py) produces 288 training cards in batch 0009, 36 development cards in batch 0010, and 48 held-out test cards in batch 0011. Consecutive negative/positive rows change one declared condition while keeping the source kind fixed. The three splits have distinct symbolic identifiers and surface frames. [Automated attestations](METHODOLOGY.md) bind the generator, cards, preview, audit, taxonomy, and IDs. No child utterance or realistic response appears in any split.

The model candidate is the pinned 4-bit RoMistral base with a new versioned [Romanian v3 prompt](../src/roguard/prompt.py). Train one rank-16 QLoRA adapter with scale 2, dropout 0.05, eight adapter layers, batch size 1, learning rate `1e-5`, prompt masking, 512-token maximum sequence length, seed 20260929, and **600 iterations**. Train only on batch 0009; use batch 0010 for logged validation loss. Evaluate the final adapter once on batch 0011. The fixed prompt-only comparators are pinned RoMistral, Qwen3 4B, Phi-4-mini, Gemma 3 4B, and Mistral 7B v0.3: the prior four-model panel plus the Romanian base. All use the same v3 prompt and 24-token generation cap. No test result will select an additional iteration under this protocol.

Report strict parsing, exact card-label matches, per-category precision/recall and false positives, exact pair matches, and correct-direction flips. Compare against an always-review reference so a high recall obtained by marking every card is visible as a failure. For R1, P1, G1, and the declared A1 word-cap subset, also keep the deterministic contract checker as the authoritative decision path. Batch 0011 measures only classification of abstract descriptions. It cannot estimate detection of real disclosures or safe real-world routing. A success on paired cards does not remove the need for independent Romanian and Ukrainian language review.
