# V12 development-calibrated category thresholds

V11 used one threshold for six scores. Its frozen batch-0023 test reached 47/72 complete abstract pairs and missed all A1 positives; the prior v10 adapter reached 53/72 pairs on the same batch. Batch 0023 is consumed and will not select this study. The v11 development scores show score-scale differences, so this experiment changes only threshold selection. It does not retrain the encoder, alter the prompt, or use the deterministic contract checker to label a text card.

Use the unchanged, hash-pinned v11 epoch-3 mmBERT LoRA adapter and the attested batch-0022 development rows. The saved epoch-3 development score file is copied byte-for-byte into `eval/runs`; its original `batch-0015` metadata tag is the documented v11 pretest error. Verify its hash, ordered row IDs, and complete report against the committed v11 selection before using it. Keep all six positive-class scores as uncalibrated research scores, not child-risk probabilities.

For each applicable code, form cutoff candidates 0, 0.5, 1, and midpoints between distinct development scores. Optimize five disjoint source groups: D1 messages; R1 routing cards; P1 permission and boundary cards; G1 gate cards; and A1 plus S1 jointly on response cards. The joint response search prevents an A1 choice from hiding S1 false labels or vice versa. Choose each group's cutoffs by most exact complete pairs, then most exact cards, then fewer false reviews on negative cards, then total distance from 0.5, then lower cutoffs. This groupwise rule maximizes the full development pair count because each card belongs to one group. Save all six thresholds, candidate counts, development report, code hashes, model hash, and sealed-test hash; commit this selection before test inference.

Batch [0024](../data/synthetic/batch-0024.preview.md) is a new 144-card Romanian abstract holdout: 12 one-fact pairs per category, rendered with a separate field and Boolean vocabulary. The typed reference validates the labels. Automated attestation checks exact duplicates and nearest same-kind character similarity against prior batches; it cannot establish independent semantics or authentic language coverage. No cards contain a child utterance, realistic response, or case paraphrase.

After the selection is committed, infer batch 0024 once with the unchanged adapter and prompt. Apply both the v12 six thresholds and the frozen v11 shared cutoff to the **same raw scores**. Preserve row scores, hashes, full metrics, and paired discordance. The predeclared symbolic-card target is at least 58/72 complete pairs, at least 9/12 positive recalls in every category, at most 7/72 false reviews on negative cards, and more complete pairs than the v11 shared-cutoff comparator. A failed target remains a recorded failure. Passing would still not establish accuracy on authentic Romanian child language, Ukrainian text, or a real disclosure or routing decision.
