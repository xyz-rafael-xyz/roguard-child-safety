# V13 frozen advisory transfer study

The six-category text classifier has repeatedly failed fresh abstract-card targets. RoGuard's operational design assigns declared R1/P1/G1 policy, permission, and workflow facts to exact checks; it also checks a declared A1 word cap locally. This study asks a narrower question about the **unchanged** selected v11 mmBERT adapter: does it recognize new abstract descriptions of D1 support-seeking patterns and S1 response-field failures without excessive false reviews? It does not evaluate real child messages, realistic disclosures, or response quality.

Use the weight file committed under `models/ro-mmbert-v11-abstract`, SHA-256 `0b2144bd7a369e0b5f422a9a309bb70cfec65682de4a530aa2a8bc6283cd50bb`, the pinned mmBERT base revision `c5955035435e2bf121cde7f3c8863ef52ff35d82`, the unchanged v4 prompt, and the v11 selected shared threshold `0.9835666418075562`. No training, development tuning, category-specific cutoff, or score transformation occurs. The A1 prompt is still scored on S1 response cards, so an erroneous A1 label makes a pair inexact.

The new [batch 0025](../data/synthetic/batch-0025.preview.md) contains 96 Romanian symbolic cards: 24 adjacent one-fact pairs for D1 and 24 for S1. A separate renderer uses new field names and Boolean wording. Typed reference rules validate both labels in each pair. Automated attestation checks reproduction, no exact duplicates, and nearest same-kind character similarity against prior batches; shared rule structures remain. The protocol, generator, attestation, model artifact, and evaluator must be committed before the test is opened.

Infer batch 0025 once and preserve row scores, decisions, exact cards and pairs, per-category TP/FP/FN and precision/recall, false reviews on the 48 negative cards, and all input hashes. The fixed symbolic target is at least **42/48 complete pairs**, at least **21/24 true positives for each D1 and S1**, and at most **4/48 false reviews on negative cards**. Also report always-review and never-review references, each of which gets zero complete pairs; always-review flags D1 on every message and S1 on every response. If the target fails, preserve the failure and do not choose a new cutoff from batch 0025. If it passes, the claim is limited to abstract-card advisory transfer; the no-realistic-disclosure data rule prevents an authentic D1 detection estimate.
