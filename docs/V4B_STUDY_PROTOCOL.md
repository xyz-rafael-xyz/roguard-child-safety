# V4b: direct-message transfer and contextual support

V4's template test showed a stronger semantic model, but its fast model falsely reviewed 48/104 Ukrainian negatives and missed Romanian positives. A second-source diagnostic had unvalidated labels and unnatural language; it is not training material. This iteration addresses the underrepresentation of varied standalone language using project-authored native phrase pairs and previously consumed v3 stems.

The new native bank contains 16 train, 12 development and 20 test pairs per language. Each produces direct-positive, ordinary-negative, personal-context-positive, fictional-context-negative and retraction-positive conversations. No new native test is scored before selection is committed. The train split includes original V4 training rows, the new training pairs and canonical old v3/v3b stems (including consumed tests), with eight exposures for each added row. Exposures and unique conversation counts are reported separately. Development and test use one exposure, distinct complete sentence pairs and distinct dialogue frames. This remains one author's synthetic task; repeated frames correlate rows. The Qwen diagnostic is excluded from fitting.

Use the registered V4 candidate grid and selection rule unchanged. Two experiments again compare lexical/semantic candidates and fixed hybrid weights. Freeze selected bytes and per-backend thresholds before evaluating the 200-row test (100 rows, 20 phrase families per language). Include earlier V4 candidates as frozen comparators on this same test. Report coverage and unresolved workload alongside forced decisions and errors; unknown outputs are never counted as correct classifications. Retain all previous results. Do not claim real-world accuracy, independent native-language validation, or statistical certainty from these small, correlated samples.
