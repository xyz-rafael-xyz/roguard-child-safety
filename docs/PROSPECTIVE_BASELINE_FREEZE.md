# Pre-author Romanian abstract-study comparator

The [registration record](../eval/prospective/ro-v16-baseline-freeze.json) fixes the existing V16 mmBERT research adapter as a **comparator** for a future independently authored Romanian D1/S1 abstract-card study. It records the pre-author Git commit `7b5f507ab136b1d89a08a83bd9186d808e2e1267`, the model revision, cutoff, maximum input length, adapter files, scoring code, packet parser, evaluator, and numeric-target protocol by exact SHA-256. It was committed before any independent batch appeared in this repository. The [verifier](../eval/verify_prospective_baseline.py) checks those bytes in CI.

This registration does not rehabilitate V16's failed synthetic transfer results or prove a prospective result. It gives future authors and reviewers a fixed comparator that cannot silently change without the verifier failing. The current [release gate](RELEASE_GATES.md) still reports independent review pending. The record's `false` flags describe the state **at registration**; they are not a live status feed after a future study begins.

The original frozen scoring code remains unchanged. A separate [input-integrity addendum](../eval/prospective/ro-v16-input-integrity-addendum.json) binds the later public annotation and evaluation wrappers, packet-binding audit, and CLI entry points before any independent batch is received. Its [verifier](../eval/verify_v16_input_addendum.py) runs in CI. The wrapper adds exact-byte binding checks to the report; it does not alter V16 weights, scoring, labels, or the registered numeric target.

For a future independent study, preserve this record and its Git history. Freeze any new candidate model separately **before** authors create its test cards; use a new record if weights, scoring code, cutoff, or evaluation target change. Give the model operator only a shuffled, opaque packet. Commit packet-bound predictions before opening adjudicated labels. The verifier checks current file bytes; Git history and the study owner's independent chronology record are still needed to establish when people wrote cards, viewed labels, or made decisions. Neither software nor a signed record establishes reviewer independence or accuracy on real child language.
