# V26: prospective bilingual latent-fact metadata study

V25 produced 165/192 complete pairs on its sealed, same-origin synthetic test. Its two Ukrainian cells were 36/48 (`D1`) and 38/48 (`S1`), below the predeclared 44/48 target. The worst failures were concentrated in unseen wording style 6. This result is preserved at `eval/prospective/v25-synthetic-result.json`; it cannot be repaired by retuning V25 on those test labels.

## Hypothesis and scope

V26 asks whether **fact decomposition followed by fixed policy composition** transfers better to new Romanian and Ukrainian metadata wording. A six-output mmBERT adapter reads only an invented abstract card and estimates D1 source role, support/safety anchor, indirect pattern, explicit request, and S1 field applicability and pass status. The D1 score is `minor × anchor × (indirect OR explicit)`; the S1 score is `applicable × NOT passed`, using continuous probabilities. The model is supervised on each latent fact, plus the composed outcome and pair ordering. A fact report makes errors auditable at the attribute level. This remains a research component; it does not screen free-form child messages or grant routing permissions.

Each language/category has 192 training pairs, 48 development pairs, and 48 sealed test pairs. Training uses seven previously written wording families (0–6). Development uses new family 7. Test uses new families 8 and 9. Romanian and Ukrainian families were drafted separately. All cards are invented annotation metadata with no child utterances, realistic disclosure, draft response, or case narrative. Labels derive from the existing typed D1 and S1 policy checks. One fact changes between paired cards. The generator records latent facts for audit, but the inference prompt reads only `language`, `source_kind`, and `text`. The model does not receive the latent fact fields while scoring.

This test is still **same-origin synthetic**. The same project authored the wording banks, oracle, model, and metric. The test seed is secret until model selection, but the code and wording families are public before fitting. A high score would support this narrow controlled transfer hypothesis only. It cannot establish idiomatic Romanian/Ukrainian quality, independent annotation agreement, child-message accuracy, safe responses, or real-world child safety. The Ukrainian taxonomy and new wording remain pending independent fluent review.

## Precommitted execution

Run `python -m training.generate_v26_facts prepare` once. It writes training and development JSONL, stores a random 192-bit test seed under ignored `review_runs/`, and commits only the seed hash, source hashes, taxonomy hashes, split hashes, and zero-test-row status. Commit and push this protocol, generator, wording banks, trainer, scorer, metric, tests, training and development rows, and commitment **before** fitting. Do not create or inspect V26 test rows during selection. Unit tests may use a separate dummy seed.

Fit the pinned `jhu-clsp/mmBERT-base` revision with one six-output LoRA head, rank 16, alpha 32, dropout 0.05, modules `Wqkv` and `Wo`, and the saved classifier head. Fixed seed `20261002`, five epochs, four pairs per batch, AdamW rate `3e-5`, 256-token cap, ten-percent linear warmup then decay. Loss is masked fact BCE plus `0.5 ×` composed-outcome BCE plus `0.25 ×` pair ranking loss. Score each epoch on development. Choose the epoch by highest worst-cell complete pairs, then overall complete pairs, correct cards, fact correctness, and earliest epoch. Choose one 0.05-grid cutoff per cell on development only. Preserve every epoch and raw development score.

A V26 model may open its sealed test only if development reaches **at least 168/192 complete pairs and at least 40/48 in each cell**. The selected adapter, cutoffs, source hashes, full development record, and eligibility flag must be committed and pushed before `reveal`. If the development gate fails, preserve the failure and create a new study; do not open V26 test. If it passes, generate test once and score the unchanged model once. Comparators are the frozen V25 model with its V25 cutoffs, a fixed character 3–5-gram logistic model fit on V26 training with cutoffs fixed on V26 development before reveal, and always/never review. No threshold, epoch, or wording change follows test reveal.

## Fixed target and report

Use the V25 strict paired target: **at least 44/48 complete pairs in every language/category cell**, at least 44/48 positives found and 44/48 negatives correctly unreviewed in each cell, all outputs finite, at least 9/12 per D1 changed factor, and at least 20/24 per S1 changed factor. Report every cell and unseen wording style, false reviews, recall, specificity, precision, Wilson intervals, and the accuracy of each latent fact. Preserve failure even when aggregate accuracy looks high. Compare the model against both frozen baselines and explicitly flag any cell where the simpler or prior model wins.

Passing this synthetic target would not make RoGuard ready to screen real children. Independent fluent language review, independently authored and adjudicated abstract cards, and the source-audit gaps in `docs/RELEASE_GATES.md` remain separate release gates.
