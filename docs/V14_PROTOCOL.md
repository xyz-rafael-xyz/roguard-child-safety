# V14 contract-aware mixed-input study

V13 passed a narrow D1/S1 abstract-card advisory test. The six-category **text-only** adapter still fails because it cannot reliably perform numeric A1 comparison and workflow interpretation across wording shifts. This study measures the actual division of labor: unchanged v11 model scores new abstract D1/S1 text, while the read-only contract checker handles separately supplied R1/A1/P1/G1 facts. It is a different input condition from a text-only classifier. Reporting both strata and a text-only comparator prevents the combined score from being mistaken for six-category language understanding.

The [sealed batch 0026](../data/synthetic/batch-0026.preview.md) contains 144 Romanian abstract cards in 72 adjacent one-fact pairs, 12 per category. A separate [contract sidecar](../data/synthetic/batch-0026.contracts.jsonl) supplies typed policy, word-count, permission/boundary, or workflow facts for R1/A1/P1/G1. D1/S1 rows have no contract sidecar and require model interpretation. Each pair's expected label is fixed by an independent symbolic scenario rule in the generator before checking the implementation. The automated audit verifies generation, sidecar hashes, exact nonoverlap, and same-kind character similarity to earlier batches. It cannot verify a real caller's policy, child age, language, or judgment. No real or realistic child communication appears.

Freeze the committed v11 adapter SHA-256 `0b2144bd7a369e0b5f422a9a309bb70cfec65682de4a530aa2a8bc6283cd50bb`, pinned mmBERT base revision `c5955035435e2bf121cde7f3c8863ef52ff35d82`, v4 prompt, and shared threshold `0.9835666418075562`. No training or cutoff selection uses batch 0026. The contract sidecar is privileged declared input: the text-only comparator sees the same card text without it. For the hybrid, score D1/S1 rows once with the frozen model and run each other row through `assess_json()` with its sidecar. A non-pass declared-contract finding counts as a review label, including a missing owner that yields `incomplete`. Preserve raw model scores on all rows, hybrid decisions, exact cards and pairs, per-category TP/FP/FN, false reviews, paired discordance, and hash-bound source files.

The prospective **mixed-input symbolic** target is ≥66/72 complete pairs overall, ≥18/24 D1/S1 advisory pairs, all 48 declared-contract pairs correct, ≥9/12 positive recalls in each category, and ≤4/72 false reviews on negative cards. Compare to the unchanged text-only model on the same 72 pairs and show the two strata separately. A passing result supports only this declared-input workflow on synthetic cards. It cannot establish authentic Romanian disclosure recognition, Ukrainian model quality, truthful caller facts, comprehension by children, or live child-safety accuracy. Batch 0026 is consumed after its first inference; a failed target remains recorded.
