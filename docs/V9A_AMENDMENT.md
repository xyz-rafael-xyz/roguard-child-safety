# V9a pretest amendment: pair-trained encoder adapter

The original [v9 protocol](V9_PROTOCOL.md) registered full-weight fine-tuning. On this 16 GB Mac, that fit completed epoch 1 (0/48 exact development pairs) and 180/216 steps of epoch 2 before it was interrupted under memory pressure: the process occupied roughly 11 GB and the machine had under 200 MB free with heavy swapping. The partial weights and development predictions remain local under `checkpoints/ro-mmbert-v9`; there is no v9 test inference or selected final checkpoint. This is a resource failure and a poor first development result, not a passed study. The interruption happened before any model opened batch 0019. Original commits retain the fixed plan.

This prospective amendment keeps the pinned mmBERT-base, Romanian v4 prompt, batches 0014/0015 for fit/development, and the already sealed batch 0019 for one final test. It fits rank-16, alpha-32 LoRA on `Wqkv` and `Wo` with dropout 0.05, retaining a trainable two-class head. There are only about 2.3 million trainable parameters. A pair is the unit of sampling: 48 one-fact pairs per category from batch 0014; every category's pairs are exposed three times, producing 864 paired exposures (1,728 card tasks) per epoch. The duplicates do not become independent examples. An initial launch failed its preflight count check before any optimizer step because the first repeat schedule totaled 672 pairs; this corrected schedule and the failed launch remain in Git history. Batch 0019 still has no model inference.

For each batch of four pairs, compute cross-entropy on both sides plus 0.5 times `softplus(negative_positive_class_margin minus positive_positive_class_margin)`. Use seed 20260930, max length 256, AdamW learning rate 1e-4, batch size four pairs, linear 10% warmup and decay, and five epochs. Save each epoch's adapter. This objective reflects the evaluation question: whether changing one decisive fact reverses the decision. It cannot make the synthetic sample representative of child language.

For each epoch, score batch 0015 once. Candidate thresholds are 0, 1, 0.5, and midpoints between sorted distinct development scores pooled across applicable categories. Choose the epoch and **one shared threshold** by complete exact development pairs, then exact cards, then fewer false reviews on negative cards, then threshold closest to 0.5, then earlier epoch, then lower threshold. Do not fit a separate cutoff per category. Commit the choice, adapter hash, and row scores before batch 0019 inference. No test inspection may alter the prompt, weights, objective, cutoff, or comparison.

On batch 0019 compare the selected v9a adapter with the frozen v8 Qwen adapter, and preserve the same raw metrics, hashes, baselines, and paired discordance as v9. The target remains ≥58/72 complete pairs, ≥9/12 positive recall in each category, ≤7/72 false reviews, and more exact pairs than v8. Report both the full-fit failure and this amended result. A pass would only support symbolic-card surface transfer; it would not validate authentic child-language detection or Ukrainian performance.
