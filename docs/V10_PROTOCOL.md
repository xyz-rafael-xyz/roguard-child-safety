# V10 cross-category negative study

The [v9a test on batch 0019](../eval/runs/ro-mmbert-v9a-test-0019.json) scored 28/72 complete one-fact pairs and 26/72 false reviews on negative cards. A1 and S1 each produced 20 false positives across their applicable response cards, even though both recovered all 12 positives. Development diagnostics showed that the pair-only fit had no training examples where a readability card was a **negative S1 task** or a support card was a **negative A1 task**. This protocol addresses that exact gap. Batch 0019 is consumed. The new [batch 0020](../data/synthetic/batch-0020.preview.md) is a separately generated and attested 144-card, 72-pair Romanian symbolic holdout with new field wording and Boolean markers, sealed before v10 fitting or inference. Its typed rules still share structure with training; it cannot measure real child-language accuracy.

## Fixed fit and development choice

Use the same hash-pinned JHU mmBERT-base, Romanian v4 prompt, and rank-16/alpha-32 LoRA on `Wqkv` and `Wo` with a trainable classification head. Initialize a new adapter from the base, not the v9a checkpoint. Use batch 0014 for fit and batch 0015 for development. Repeat each of the 288 one-fact training pairs three times. For every response pair, add two negative tasks for the *other* applicable response category: an A1 pair adds S1 negatives on both cards; an S1 pair adds A1 negatives. This adds 576 cross-category task exposures per epoch to 1,728 primary card exposures. No new unique card is created.

Use seed 20260930, batches of two pairs (at most eight card tasks), maximum length 256, AdamW learning rate 1e-4, linear 10% warmup and decay, and three epochs. For each batch, minimize primary two-class cross-entropy plus 0.5 times the positive-versus-negative pair `softplus` ranking loss. If the batch contains response pairs, also add 0.5 times the two-class cross-entropy of their cross-category negative tasks. Save every epoch. The auxiliary loss tests whether a rule can be rejected when it is applicable to the same source kind but unsupported by that card.

Use the same **one shared threshold** selection as v9a. For each epoch, score only batch 0015; try 0, 0.5, 1, and midpoints between distinct pooled development scores. Select by complete exact pairs, exact cards, fewer false reviews on negative cards, threshold closest to 0.5, earlier epoch, then lower threshold. Commit the selected epoch, threshold, adapter hash, and development predictions before batch 0020 inference. No test-informed change may be made to the fit, prompt, or cutoff.

## Frozen test and decision

Run the selected v10 adapter once on batch 0020. Run the already frozen v9a adapter and v8 Qwen adapter as comparators on the same cards under their own committed thresholds and parsers. Preserve row scores and predictions, strict validity, exact cards and pairs, directional flips, negative-card false reviews, per-category TP/FP/FN and precision/recall, hashes, and paired discordance. Include always-review and never-review references. V10 meets the **symbolic-card** target only at ≥58/72 complete pairs, ≥9/12 positive recall for every category, ≤7/72 false reviews, and more exact pairs than both comparators. Failures stay visible and require a new study with a new sealed test; repeatedly measuring batch 0020 cannot create independent evidence.
