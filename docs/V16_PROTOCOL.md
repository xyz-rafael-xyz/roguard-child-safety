# V16 Romanian advisory prose repair

V15 failed on a new abstract prose rendering with the unchanged v11 model: 23/48 complete D1/S1 pairs, nine false D1 reviews, and S1 recall 8/24. This prospective study tests a specific repair: continue the selected v11 mmBERT LoRA adapter on several new Romanian abstract prose families, then select a shared cutoff on separate development prose. V15 cards, labels, and scores are excluded from training and cutoff selection. The intervention is wording exposure, not a new safety policy.

The [training batch 0028](../data/synthetic/batch-0028.preview.md) contains 384 cards in 192 adjacent one-fact pairs: 96 D1 and 96 S1 pairs, rendered in four forms. [Development batch 0029](../data/synthetic/batch-0029.preview.md) has 48 cards in 24 pairs. [Test batch 0030](../data/synthetic/batch-0030.preview.md) has 96 cards in 48 pairs from a sixth prose form. All state labels come from typed reference checks before fitting; all text describes fictional fields rather than child messages or realistic replies. Exact duplicates and a sample of training-surface similarity are audited; every development and test row receives a similarity check. Typed state structures remain shared across splits, so this is a narrow surface-transfer test.

Start from the committed v11 adapter weight SHA-256 `0b2144bd7a369e0b5f422a9a309bb70cfec65682de4a530aa2a8bc6283cd50bb` and pinned JHU mmBERT-base revision `c5955035435e2bf121cde7f3c8863ef52ff35d82`. Keep the v4 Romanian prompt and rank-16 adapter structure. Fit three epochs on batch 0028 only with seed 20260930, batches of two pairs, maximum 256 tokens, AdamW learning rate `3e-5`, 10% warmup then linear decay. Use primary cross-entropy, `0.5` pair-ranking loss, and `0.5` A1 cross-negative loss on S1 response cards. At each epoch, score batch 0029 and choose one shared cutoff from 0, 0.5, 1, and midpoints between pooled development scores. Select by exact development pairs, then exact cards, fewer false reviews, cutoff nearest 0.5, earlier epoch, then lower cutoff. Commit selected weights, cutoff, and row-level development predictions before opening batch 0030.

On batch 0030, compare the selected V16 adapter with the **unchanged** v11 adapter and its original cutoff. Count full exact cards/pairs, D1/S1 TP/FP/FN and precision/recall, false reviews on 48 negatives, A1 cross-category errors, and strict prediction validity. V16 meets the fixed target only with **at least 42/48 exact pairs**, **at least 21/24 positive recalls in both D1 and S1**, **at most 4/48 false reviews**, and **more exact pairs than unchanged v11 on the same test**. Save all score vectors and input hashes. Preserve a failure if any condition fails. Success would establish only abstract prose-card transfer; no realistic disclosure content or authentic-language accuracy is tested.
