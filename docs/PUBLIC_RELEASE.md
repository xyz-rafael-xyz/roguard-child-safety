# Public source release

Version 3.0.2 publishes the same v3 model as the `roguard-child-safety` PyPI distribution; `pip install roguard-child-safety` installs the latest published version. The [v3 study scope](V3_MESSAGE_RELEASE.md) gives its exact synthetic results and limits. [Version 3.0.1](V3_0_1_RELEASE.md) introduced the direct GitHub release archive, which remains available. The earlier [v2](V2_RELEASE.md), [v1.1.1](V1_1_1_RELEASE.md), [v1.1.0](V1_1_RELEASE.md), and [v1.0](V1_RELEASE.md) notes remain historical release records. The declared-contract checker and abstract-card evaluation tools remain available.

This repository began as a source-only snapshot of RoGuard at private research commit `f1b2c0bacddb6d319b35b91da09381f5d8f34aa3` and has since received public toolkit fixes. It contains the Romanian and Ukrainian declared-contract checker, taxonomies, synthetic data and research records, examples, and documentation. It has a separate public Git history so earlier private commits cannot expose research artifacts through a clone. Later public CLI fixes do not change the separately frozen private V16 study source or its recorded results.

The older selected adapter weights and configs are **not** in this repository. They remain in a separate private research archive, and their prior scores cannot be replayed from this checkout. The new v3 character-model weights are included; their training banks, generation code, selection files, and test results can be replayed from this public tree. The v3 scorer is experimental and is not validated as a detector for real child messages. The contract CLI continues to check caller-declared facts without model inference.

Public CI runs the package and contract tests on Python 3.9 through 3.14, checks synthetic batch structure, installs a wheel outside the checkout on Python 3.9, 3.12, and 3.14, exercises the packaged bilingual v3 scorer, and scans the public Git tree and history for withheld artifact paths and credential-shaped text. Tests that require older private weights explicitly report `skipped`.

The [release-gate record](RELEASE_GATES.md) describes the remaining language-validation and real-world accuracy work. Public availability does not change those gates.
