# RoGuard Local v1.0.0 release scope

RoGuard Local v1.0.0 is an installable, offline Romanian and Ukrainian toolkit for checking **caller-declared** child-safety decision contracts. The released wheel includes the CLI, Python API, JSON schemas, Decision Studio, one-fact explorer, contrast and agreement tools, corrected-v1 structured contract checks, and research utilities for abstract-card review. Checks return results for a human; they do not notify, report, change access, or make legal or clinical determinations.

The corrected Romanian and Ukrainian taxonomy texts have exact-byte, owner-attested specialist acceptance records. Reviewer names and contacts remain private. The package keeps those historical `*_v1_candidate.md` filenames to preserve the reviewed digests. Software verifies document structure and hashes, not reviewers' identities or language quality. See the [taxonomy disposition](TAXONOMY_REVIEW_V1.md) and [evidence ledger](V1_EVIDENCE.md).

The wheel contains **no trained text-model weights**. The private research archive contains experimental Romanian and Ukrainian models whose synthetic wording transfer has been unstable. The owner's final eight-file external author archive was preserved and audited as received; it does not test the registered D1/S1 factors, so it yields no independent D1/S1 accuracy score. This release therefore makes no claim of high accuracy on child messages, validated disclosure detection, or automatic guardian routing. The model-validation gate stays open independently of the v1.0 package version.

Install from the tagged GitHub release wheel, or clone the tag and run `python3 -m pip install .` in a virtual environment. Python 3.9 through 3.14 are exercised in CI. Run `python -m roguard examples/contracts_ro.json` and `python -m roguard examples/contracts_uk.json` from the source checkout for two local examples. `roguard-v1-contract examples/v1_candidate_ro.json` and the Ukrainian counterpart exercise the corrected structured contract rules. No model download or network connection is needed to run these checks.

The release's reproducible checks cover schema validation, declared-contract outputs, input-integrity failures, bilingual CLI behavior, wheel installation, and the public-tree privacy audit. Private model-dependent scores require withheld adapter weights and are labeled author-reported in the [benchmark ledger](../BENCHMARK.md). A caller must supply accurate facts and an explicit policy; passing a contract check cannot prove that those inputs are true or that a real response is safe.
