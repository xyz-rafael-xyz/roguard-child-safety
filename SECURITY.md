# Security

For a vulnerability in code or the review gate, use GitHub's [private vulnerability report](https://github.com/xyz-rafael-xyz/roguard-child-safety/security/advisories/new) before public disclosure. Do not open a public issue with exploit details. Use only abstract, synthetic reproduction inputs; never include child data, example disclosures, private reviewer material, credentials, or personal data. The prototype has no external escalation or reporting integration.
